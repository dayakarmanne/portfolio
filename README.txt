DAYAKAR MANNE — PORTFOLIO TEMPLATE

Files
- index.html: page structure and content
- style.css: responsive dark/cyan design, 3D-inspired CSS art and animations
- script.js: mobile navigation, scroll progress, reveal animations, pointer tilt

Run
1. Extract the ZIP.
2. Open index.html in a modern browser.
3. For deployment, upload all three files to your static host (e.g. GitHub Pages, Netlify, or your own hosting).

Customize
- Update the content directly in index.html.
- Update colors and spacing via CSS variables at the top of style.css.
- Add a real portrait by replacing the CSS-generated hero visual with an image element.
- The CV button is intentionally omitted until you provide a resume file/link.
- Project summaries and technical stack are based on the information supplied; edit them to match the exact implementation and technologies used.
